# TKM-M0-003 — Cosmos DB + MemoryUnits container

## Context

The MemoryUnit is the atomic primitive of [[takumi-os-quantized-memory]]
— every memory captured from Teams / Outlook / Jira / HubSpot / etc.
is quantised into a MemoryUnit document, persisted to Cosmos DB, and
then indexed downstream by AI Search. Without Cosmos, M0 has no
persistence. This ticket creates the account, the 10 containers, and
the private-endpoint wiring per [[takumi-os-azure-architecture]]
§Data Architecture.

## What this ticket delivers

- `terraform/modules/cosmos/` — Cosmos account + 10 containers
  + private endpoint + diagnostic settings + (optional) customer-
  managed key wiring for prod
- Wire into `env/dev/main.tf` and `env/test/wire.tf`
- `env/prod` is a placeholder until R3 per the existing pattern
- Ticket file

## Container list (10)

Per DIP §5:

| Container | Partition key | TTL | Indexes |
|---|---|---|---|
| `MemoryUnits` | `tenantId` | none (0) | SourceSystemId, MemoryType, confidenceScore, createdAt |
| `KPIs` | `tenantId` | 0 | name, ownerId |
| `Initiatives` | `tenantId` | 0 | ownerId, status, dueDate |
| `Processes` | `tenantId` | 0 | owner, status |
| `Projects` | `tenantId` | 0 | owner, status |
| `Decisions` | `tenantId` | 0 | madeBy, relatedProjectId |
| `Risks` | `tenantId` | 0 | severity, status, owner |
| `Recommendations` | `tenantId` | 0 | agentId, confidence |
| `JobRuns` | `tenantId` | 30 days | status, startedAt |
| `SourceEvents` | `tenantId` | 90 days | sourceSystemId, eventType, receivedAt |

All partition by `tenantId` to make multi-tenant isolation
automatic and per-tenant queries efficient.

## Approach

1. Build `modules/cosmos/` with: account (SQL API), database,
   10 containers (for-loop), private endpoint, diagnostic
   settings, optional CMK
2. Wire `env/dev/main.tf` to add a `cosmos` module call
3. Wire `env/test/wire.tf` to add a `cosmos` module call
4. HCL syntax check
5. Commit; update kanban + wiki handoff

## What this ticket does NOT deliver

- Cosmos DB connection strings into Key Vault (R2: app
  bootstrap adds them; M0 dev uses `~/.hermes/.env`)
- The actual MemoryUnit document insert/query code (TKM-M0-007)
- AI Search index (TKM-M0-016)
- Neo4j graph (R2, per [[0002-knowledge-graph-neo4j]])
