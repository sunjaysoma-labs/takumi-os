# TKM-M0-002 — Terraform foundation

## Context

The first IaC ticket in the [[takumi-os]] M0 build. The 5 modules
here are consumed by every subsequent ticket — TKM-M0-003 (Cosmos)
attaches to the Data subnet, TKM-M0-005 (Identity Service) deploys
to AKS, TKM-M0-008 (Knowledge Acquisition Service) subscribes to
Service Bus topics, TKM-M0-033 (Observability) builds on the
monitoring module.

## What this ticket delivers

- 5 Terraform modules in `terraform/modules/`
- 3 environment configs in `terraform/env/{dev,test,prod}/`
- tfvars files with sensible dev defaults; test/prod left empty
- README at `terraform/README.md` explaining the module graph
- 1 `terraform/versions.tf` pinning provider + Terraform versions

## Module dependency graph

```
networking  ←  aks  ←  (downstream services attach to AKS)
       \         \
        \         └  monitoring  ←  servicebus
         \
          └  keyvault  (peered to all subnets via private endpoint)
```

## Conventions

- **Per [[0003-monorepo-vs-polyrepo]]:** all modules in this single
  repo
- **Per [[takumi-os-azure-architecture]] §Resource group structure:**
  - `rg-takumi-dev` (dev)
  - `rg-takumi-test` (test)
  - `rg-takumi-prod` (prod)
- **Per [[0005-microsoft-fabric-m2]]:** `enable_fabric = false`
  in all envs (Fabric provisioned but unused until R2)
- **Per DIP §19 (Kanban M0 implementation order):** Foundation
  phase is ticket 1-4; this is ticket 2

## What this ticket does NOT deliver

- Service-specific Helm charts / Kustomize overlays (TKM-M0-005+)
- The 5 Microservices Terraform module wrappers (each service
  gets its own in a later ticket)
- Cosmos (TKM-M0-003), Azure SQL (TKM-M0-004), Neo4j (separate)
- Workload identity / Entra ID app registrations (TKM-M0-005)

## Approach

1. Pin Terraform + provider versions in `versions.tf`
2. Build modules bottom-up: networking → keyvault → monitoring →
   servicebus → aks (aks depends on networking, monitoring, and
   keyvault)
3. Wire 3 env configs
4. Document in `terraform/README.md`
5. Write ticket file in `tickets/M0/TKM-M0-002.md`
6. Commit; update wiki handoff
