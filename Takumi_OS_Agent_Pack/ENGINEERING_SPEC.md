# Takumi OS Engineering Specification
Core principles: Memory First, Event Driven, Multi-Tenant, AI Agnostic, Graph Centric, Microsoft Native.
Frontend: Next.js 15, TypeScript, Tailwind, Shadcn.
Backend: FastAPI modular monolith.
Datastores: PostgreSQL + Neo4j.
Core modules: Dashboard, Memory Engine, Agents, Risk Center, Intelligence Hub.
AI Provider abstraction: MiniMax, OpenAI, Anthropic, Gemini.
